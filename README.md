# UpStartInterns - Task 1

## Project: Arrays and Formatted Output

This Java program performs the following operations:

- Takes numbers from the user.
- Calculates the sum and average.
- Finds the largest and smallest numbers.
- Sorts the array.
- Displays formatted output using printf().
- Handles invalid input.

## Technologies Used

- Java
- Scanner
- Arrays
- printf()

## How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

   javac Task1.java

5. Run the program:

   java Task1
